# Shane Construction Corporation

Responsive React website built with Vite. Run `npm install` and `npm run dev`; run `npm run build` for a production bundle in `dist`.

Includes mobile navigation, project filters and detail dialogs, FAQs, and an inquiry brief download. The form does not send inquiries to a server. Add verified company contact details and a backend or form service before enabling online submissions.

Project images are illustrative Unsplash photography, not claims of completed company projects. Replace concept cards with verified portfolio details before launch. Images and Google Fonts require an internet connection.
